# Research paper (GitHub Pages)

This folder is published via **GitHub Pages** from the `main` branch (`/docs`). The entry point is **`index.html`** — a standalone research paper on refresh prioritisation for the FlyRank ML internship capstone. Figures live in `assets/` as SVG files referenced by the HTML.

The paper is self-contained: no JavaScript, no external fonts or CDNs, and no client-identifying fields. Headline metrics use the w06 LOO-client audit (P@50 = 0.258 ± 0.237).
